# Credits

All art in this prototype is generated procedurally at runtime in GDScript
(`scripts/tex.gd`, `scripts/city.gd`, `scripts/car.gd`, `scripts/ped.gd`):
asphalt, sidewalk, grass, roof and window-facade textures, and every car, pedestrian,
building and prop mesh. No third-party assets are used.

- Engine: Godot Engine 4.7.2-stable (MIT licence), https://godotengine.org
- Font: Godot's built-in default font.
